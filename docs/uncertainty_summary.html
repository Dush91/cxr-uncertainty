Chest X-ray · Uncertainty Detection

How we tell a model “I don’t know”

A plain-language summary of the uncertainty-calculation work — no jargon walls, just what each flag does and where it earns its keep.

The problem

A chest X-ray model can be confident and wrong. A single model just hands you a probability — it cannot say “I don’t know.” We want a system that, for each image, can flag: “I’m confident here, but I might be wrong — get a human to look.”

What the ensemble gives us

Instead of one model, we run three different model architectures on each X-ray:

xrv DenseNet
a classic supervised CNN
ConvNeXt-V2
a modern ImageNet-trained CNN
RAD-DINO
a self-supervised Vision Transformer

The key idea: these models were trained in genuinely different ways, so when they disagree, that disagreement is real signal about uncertainty — not just one model’s quirk. For each pathology we compute:

  • p_bar — the average prediction across the 3 models (the “consensus”)
  • epistemic_std — how much the 3 models disagree (the spread)
  • mutual information — a related information-theoretic measure of disagreement

The three flags

1

Disagreement

in-distributionat chance under shift

If the models are confident (p_bar far from 0.5) and they disagree a lot (high epistemic_std), we flag it high-risk. The simple, intuitive uncertainty flag.

The catch we discovered: under distribution shift (a pediatric pneumonia dataset, a COVID dataset — images the models never trained on), this flag goes to chance. All 3 models confidently agree on the wrong answer, so disagreement literally cannot see it. This is the central honest finding of the project.
2

Conformal triage

coverage guaranteebreaks under shift

For each pathology we fit a threshold so the true label lands in our predicted “set” ≥90% of the time on in-distribution data. If the set isn’t a single label → refer to a human. A mathematical promise the disagreement flag can’t make.

Honest result: in-distribution coverage holds (0.88–0.91); under shift it breaks (0.27/0.25). The guarantee is only as good as the distribution it was fit on. Complementary to disagreement — both fail under shift.

3

Mahalanobis OOD survives shift

the breakthrough

Instead of “do the models agree?” we ask “is this image far from the images the models were trained on?” We take RAD-DINO’s internal feature vector for the image and measure its distance to the cloud of in-distribution features (a class-conditional Gaussian, fit on OpenI Pneumonia positive/negative). High distance = out-of-distribution = likely wrong.

Why it works where disagreement fails: it looks at the input representation, not model agreement. When all 3 models confidently agree on a wrong pediatric-pneumonia call, the Mahalanobis score is still high — the image itself looks foreign.

Calibration — the prerequisite

Raw model probabilities are over/under-confident, so we calibrate before interpreting uncertainty. After testing, we landed on temperature scaling only — a single temperature applied to the pooled average. We explicitly rejected per-model Beta calibration: it smooths each model onto a common scale and erases the very disagreement signal that carries the uncertainty. Calibrate the mean; leave the disagreement raw.

The per-image recipe (what the demo runs)

  1. Load the image, run all 3 models → per-pathology probabilities
  2. Average → p_bar; measure spread → epistemic_std
  3. Threshold flag: confident AND disagreeing?
  4. Conformal flag: apply pre-fit thresholds, is the set ambiguous?
  5. Mahalanobis flag: extract the RAD-DINO feature, score its distance, report as a percentile vs in-distribution OpenI

One demo subtlety worth knowing

Fair reference matters. The Mahalanobis percentile needs a fair baseline. Comparing each image against the OpenI images the Gaussian was fit on fails — those sit artificially close to their own centroid, so every new image looks out-of-distribution. The fix: use a held-out OpenI set (same distribution, not used in fitting) as the reference. Result: normal OpenI images ~57–90th percentile, OOD Kermany/COVID ~99.5th — a clean split.

Bottom line

  • Disagreement — simple, works in familiar territory, useless under shift.
  • Conformal — adds a real coverage promise, but only in-distribution.
  • Mahalanobis — the safety net that actually fires when the world changes. The only one that beats chance under distribution shift.

That’s the story the demo tells in one click: a pediatric pneumonia X-ray where all 3 models confidently agree (disagreement flag quiet), but the Mahalanobis gauge spikes to the 99th percentile and the banner goes red.
